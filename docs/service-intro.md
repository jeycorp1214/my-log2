# mylog — 서비스 소개

> **"서버 없는 담백한 기록, 데이터의 주인은 나"**

---

## 한 줄 소개

mylog는 알림 없이, 서버 없이, 조용하게 관계와 일상을 기록하는 모바일 앱입니다.

---

## 누구를 위한 앱인가

**20-40대 중 이런 사람.**

- SNS 알림에 지쳐 "내가 먼저 연락하고 싶을 때 하는" 관계를 원하는 사람
- 지인 생일·기념일을 기억하고 싶지만 SNS에 알리긴 싫은 사람
- 구독료 없이 한 번 사고 오래 쓰는 앱을 좋아하는 사람
- 내 데이터가 어디 서버에 쌓이는 게 불편한 사람
- 할일 목록, 메모, 관계 기록이 하나로 연결되길 원하는 사람

---

## 핵심 가치

### 🔒 데이터 주권 (Local-first)

모든 데이터는 내 폰 안에만 있습니다. 서버가 없습니다. 해킹당할 서버도, 회사가 망해도 사라질 데이터도 없습니다. 백업이 필요하면 내 Google Drive에 직접 보냅니다.

### 🔕 알림 없는 자발적 기록

앱이 먼저 "기록하세요"라고 조르지 않습니다. 내가 열고 싶을 때 엽니다. 연락하고 싶을 때 연락합니다. 앱이 관계를 강요하지 않습니다.

### 🧘 간결한 UI

필요한 것만 있습니다. 화려한 대시보드, 소셜 기능, 추천 알고리즘 없습니다. 기록이 전부입니다.

---

## 주요 기능

### 프로필 관리

- 관계별 태그 (친구, 직장, 가족 등)
- 연락 주기 설정 — "3개월 안에 연락 안 한 사람" 필터
- 첫 만남 날짜, MBTI, 생일 기록
- 지인별 기념일 (D-Day 계산 포함)
- 지인과 연결된 일정·기록 타임라인

### 캘린더 & 로그

- 일정 기록 + 반복 설정 (매일/매주/매월/매년)
- 여러 사람을 하나의 일정에 연결 ("김철수, 이영희와 점심")
- 캘린더·리스트 뷰 전환

### 노트 탭

- 메모 (핀 고정 지원)
- 할일 — 아이젠하워 매트릭스 (긴급/중요 4분면)
- 마감일, 필터, 빠른 입력바

### 통계

- 연간 잔디 히트맵 (기록 밀도)
- 가장 많이 만난 사람 랭킹
- 카테고리 비율, 스트릭, 완료율
- MBTI 분포, 동반 빈도

### 보안

- 6자리 PIN 잠금 (iOS Keychain / Android Keystore)

### 백업

- Google Drive App Data Folder — 단일 파일, 자동 덮어쓰기
- 암호화 JSON 내보내기 (Share Sheet)

## 브랜딩 방향 아이디어

### 핵심 메시지 후보

1. **"조용한 관계 기록장"** — 소셜미디어 피로감 세대 공략
2. **"내 데이터는 내 폰 안에"** — 개인정보 의식 높은 유저 공략
3. **"알림 없이, 서버 없이, 나답게"** — 미니멀리스트 정체성
4. **"관계도 기록이 쌓이면 깊어진다"** — 관계의 질 강조

### 톤앤매너

- 차분하고 신뢰감 있는 톤 (불안 유발 금지)
- 개인 공간·프라이버시 이미지
- 과장 없음 — "혁신", "AI 추천" 같은 키워드 지양
- 잔잔한 일상미 (다이어리 감성)

### 색상 방향

- 딥 네이비 or 차콜 (신뢰, 프라이버시)
- 포인트: 소프트 코랄 or 모스 그린 (따뜻함)
- 과한 원색 금지

### 스토어 키워드 후보

관계 관리, 인맥 다이어리, 연락처 일지, 관계 일기, 지인 기록, 비공개 다이어리, 오프라인 메모, 로컬 저장 앱, 연락 주기, 관계 캘린더

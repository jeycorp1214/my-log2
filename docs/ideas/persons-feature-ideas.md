## 구현 완료

| #   | 기능                             | 비고                                          |
| --- | -------------------------------- | --------------------------------------------- |
| 1   | 관계 태그 (tags)                 | DB 컬럼 + PersonForm + PersonCard             |
| 2   | 연락 주기 알림 (contactInterval) | DB 컬럼 + PersonForm + PersonCard 배지        |
| 3   | 인물 상세 타임라인 뷰            | TimelineItem.tsx                              |
| 5   | 첫 만남 날짜 (metAt)             | DB 컬럼 + PersonForm                          |
| 9   | 통계 카드                        | PersonStatsCard.tsx                           |
| 10  | 즐겨찾기/고정 (isPinned)         | DB 컬럼 + 롱프레스 토글 + 목록 상단 고정 섹션 |
| —   | 이니셜 아바타                    | PersonCard 내 이름 해시 기반 원형 아이콘      |
